In progress

Cloud-Deployed Task & Team Workflow API

A multi-user task management API with full CRUD, task status and priority, due dates, and per-user ownership — each user only sees their own tasks. JWT registration and login with hashed passwords and correct HTTP status codes (201 on creation, 404 for missing resources, 401 when unauthorized). Deploying to AWS on EC2 behind security groups, with data in a managed PostgreSQL database (RDS).
